# Microcontroller Projects

## Overview

This repository contains a collection of Embedded C and microcontroller-based projects developed as part of the Microcontroller (MC) module during Emertxe Embedded Systems training.

The projects demonstrate practical implementation of microcontroller peripherals and embedded programming concepts, including timers, interrupts, PWM, UART communication, EEPROM interfacing, sensor interfacing and LCD-based applications.

## Projects

### 1. 4-Digit Key Press Counter with Persistence using External EEPROM

- Implements a 4-digit key press counter.
- Uses external EEPROM for persistent data storage.
- Demonstrates EEPROM interfacing and data retention.

**Folder:** `01_External_EEPROM_Persistence`

### 2. LED Dimmer using PWM (Time ISR Based)

- Implements LED brightness control using PWM.
- Uses timer interrupt-based timing.
- Demonstrates PWM generation and duty-cycle control.

**Folder:** `02_PWM_LED_Dimmer`

### 3. Temperature Sensor Node with CLCD Display

- Interfaces a temperature sensor with a microcontroller.
- Displays temperature readings on a Character LCD.
- Demonstrates sensor interfacing and LCD communication.

**Folder:** `03_Temperature_Sensor_CLCD`

### 4. System Sleep and Wake-up on Interrupt Change

- Implements microcontroller sleep mode.
- Demonstrates interrupt-based wake-up functionality.
- Explores low-power embedded system operation.

**Folder:** `04_Sleep_Wakeup_Interrupt`

### 5. Message Display using UART and CLCD

- Implements UART-based message reception.
- Displays received messages on a Character LCD.
- Demonstrates serial communication and peripheral interfacing.

**Folder:** `05_UART_CLCD_Message_Display`

### 6. Stopwatch with 5 Laps

- Implements a stopwatch application with five lap records.
- Demonstrates timer-based time measurement and application logic.

**Folder:** `06_Stopwatch_5_Laps`

## Concepts Covered
